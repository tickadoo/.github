# tickadoo engineering standards

This repository is the canonical, public source for tickadoo's engineering,
contribution, pull-request, and vulnerability-reporting standards.

GitHub automatically offers the default `CONTRIBUTING.md`, `SECURITY.md`, and
pull-request template to organization repositories that do not define a local
override. Repository-specific guidance may add stricter requirements, but must
not weaken the company-wide safety baseline in `AGENTS.md`.

Author-controlled merge authority and risk-appropriate independent review are
defined only in `AGENTS.md`. Required CI and review establish technical
readiness; the author must explicitly choose to merge through an approved
path. Existing merge and release holds retain their scope.

No credentials, internal URLs, customer data, or confidential operating details
belong in this repository.
